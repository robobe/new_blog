## UAV123

UAV123 Dataset is a dataset for an object detection task. It is used in the drone inspection domain.

The dataset consists of 113476 images with 109866 labeled objects belonging to 10 different classes including person, car, group, and other: wakeboard, boat, uav, bike, building, truck, and bird. [more](https://datasetninja.com/uav123)
